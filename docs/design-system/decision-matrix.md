# Design-system decision matrix

Every decision in the owner's submitted payload, what was selected, where it lives, and what
proves it. The payload is kept verbatim in [decision-payload.txt](decision-payload.txt)
(schema `wl-ds-workbook/v1`, 65 selected, 0 unresolved, 0 deferred). The "Accepted meaning"
column quotes the workbook's own title and summary for the selected option.

`scripts/policy-consistency.test.ts` fails when a selected option is missing here or in
[DESIGN_SYSTEM.md](../../DESIGN_SYSTEM.md), or when this file names an option that was not
selected. Rows marked **OPEN** or **BLOCKED** are not complete; see DESIGN_SYSTEM.md,
Validation status.

¹ Not the workbook's recommended option. Selected deliberately by the owner.
