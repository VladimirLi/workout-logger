# Icon licences

Every icon the web app renders is listed here. `apps/web/ui/icons/icons.test.ts` fails when
`geometry.ts` contains an icon this ledger does not list, or the ledger lists one it does not
contain (iconography.def.licence, docs.source.repo-md-lab).

**Source:** `lucide-static@1.46.0`, geometry copied unmodified. No npm dependency is added,
so the licence gate and the LIC-2026-09-16 ledger are unaffected. **Style:** outline,
stroke 1.75, round caps and joins (iconography.style.outline-lucide).

**Licence:** ISC, Copyright (c) 2026 Lucide Icons and Contributors. Icons derived from the
Feather project are additionally MIT, Copyright (c) 2013-present Cole Bemis. Both notices
are kept in full in [LICENSE-lucide.txt](LICENSE-lucide.txt), in a preserved comment in
`geometry.ts`, and in the served `/third-party-notices.txt`.

The app icon (three rising bars) is original project artwork and is not listed here.
